# PiPantry
PiPantry is a smart pantry and ingredient inventory management system designed to help users track ingredients and find recipes. This project combines a Raspberry Pi, camera-based scanning, and a Java Desktop Application to identify and manage food items. This was completed in Spring of 2026 alongside @marissa9197, @rayash101, @linhylee, @Joy-cs77, and @arachide0724.
